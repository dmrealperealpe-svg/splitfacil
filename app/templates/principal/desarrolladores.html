API de SplitFácil

Lee y crea gastos desde otras aplicaciones. Responde en JSON.

Cómo autenticarte

Inicia sesión, abre tu perfil y crea un token personal. Envíalo en cada petición:

curl {{ base }}/api/grupos \
  -H "Authorization: Bearer sf_tu_token"

Si algo falla, la respuesta trae el código HTTP correcto y un JSON con el motivo:

401 {"error": "No autenticado", "detalle": "Envía tu token..."}
403 {"error": "Acceso denegado", "detalle": "No tienes permiso..."}
404 {"error": "No encontramos esa página", ...}
422 {"error": "Datos no válidos", "errores": {"monto": "El monto debe ser..."}}

Endpoints

GET/api/salud

Público. Responde {"estado": "ok"} si la app y la base de datos funcionan.

GET/api/categorias

Público. Las categorías disponibles para clasificar un gasto.

GET/api/yo

Tus datos básicos.

GET/api/grupos

Tus grupos con tu saldo en cada uno (positivo: te deben; negativo: debes).

{
  "te_deben": 0,
  "debes": 276667,
  "grupos": [
    {"id": 1, "nombre": "Apartamento 5B", "emoji": "🏠",
     "n_miembros": 3, "n_gastos": 3, "tu_saldo": -276667}
  ]
}
GET/api/grupos/<id>

Detalle de un grupo: integrantes, total gastado y tu saldo.

GET/api/grupos/<id>/gastos

Lista de gastos, paginada. Parámetros opcionales: q (buscar), categoria, pagina, por_pagina (máx. 50).

POST/api/grupos/<id>/gastos

Crea un gasto. Responde 201 Created con la dirección del nuevo gasto en la cabecera Location. Si omites participantes, se reparte entre todo el grupo; si omites pagado_por, pagas tú.

curl -X POST {{ base }}/api/grupos/1/gastos \
  -H "Authorization: Bearer sf_tu_token" \
  -H "Content-Type: application/json" \
  -d '{"descripcion": "Pizza", "monto": 60000, "categoria": "comida"}'
GET/api/grupos/<id>/gastos/<id>

Un gasto con su reparto por persona.

DELETE/api/grupos/<id>/gastos/<id>

Borra un gasto (solo quien lo creó o el propietario del grupo). Responde 204 No Content.

GET/api/grupos/<id>/saldos

El saldo de cada integrante y la lista mínima de pagos para dejar todo en cero.

Los montos son enteros en pesos colombianos (sin decimales).
